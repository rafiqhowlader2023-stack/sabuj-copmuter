# অ্যাডমিন প্যানেল (Android)

`app/src/main/assets/index.html` ফাইলটি WebView-তে চলে। HTML বদলালে শুধু ওই ফাইল replace করে push করুন।

## GitHub দিয়ে APK বানানো
1. GitHub-এ নতুন repo খুলুন, এই ফোল্ডারের সব ফাইল push করুন (`.github` ফোল্ডারসহ)।
2. repo → **Actions** ট্যাবে "Build APK" চলবে (বা Run workflow চাপুন)।
3. শেষ হলে run-এর নিচে **Artifacts → AdminPanel-APK** ডাউনলোড করুন।
